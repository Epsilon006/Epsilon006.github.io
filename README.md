# Epsilon006 · Beyond the Rain

A static GitHub Pages homepage with no dependencies or build step. The original Miku illustration and repository links are preserved.

## Local preview
Extract the archive and open index.html, or serve this directory with any static file server.

## Publishing
Copy index.html, styles.css, app.js, favicon.svg, .nojekyll, and the assets directory into your existing GitHub Pages publishing directory. Keep their relative paths intact. Preserve your existing CNAME file if you use a custom domain. Published at https://epsilon006.github.io/. The GitHub profile links to this site, and the previous /Epsilon006/ address redirects here.

## Interaction
- Move the pointer to influence wind, rain, water ripples, parallax, and the mist.
- Hold and drag to wipe the glass. The mist gradually returns.
- On mobile, drag across the upper illustration to wipe the mist; scroll through the content below.
- Rain adjusts rainfall density. Set it to zero to stop falling rain.
- Reset mist restores the fog layer.
- Pause motion stops automatic animation. Wiping and controls remain available.
- Close the glass with the close button or Escape. Reopen it with the button in the rain scene.
- Reduced-motion preferences are respected. Animation stops when the tab is in the background.

## Editing
Edit identity, copy, and repository links in index.html; appearance and responsive layout in styles.css; weather and mist behavior in app.js. The supplied illustration is assets/cyber-muse.png.

## Validation
The original redesign was checked for JavaScript syntax, browser errors, desktop and 390px mobile layout, wiping, pause, rain intensity, close, and reopen behavior. Repository links are preserved from the supplied project; remote repository contents have not been verified.


## Soundscape
Use an HTTP server for local audio playback. Sound is opt-in. Rain and birds are continuous, long field-recording loops. Rain intensity controls the rain layers; Volume controls overall loudness. Time defaults to the visitor's local clock, with optional Dawn/Day/Dusk/Night overrides. This is an artistic time-of-day mix, not local weather or astronomical sunrise data. Source attribution and licenses are retained in [audio-credits.html](audio-credits.html); there is no Credits control on the homepage. Publish all HTML/CSS/JS files and the complete assets directory.
